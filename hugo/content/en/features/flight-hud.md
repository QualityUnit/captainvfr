# Flight HUD (Heads-Up Display)

Stay informed with critical flight data always visible on your screen. The Flight HUD provides essential flight information in a clean, collapsible interface that doesn't obstruct your map view.

## Key Features

### Collapsible Design
- **Compact Mode**: Shows only essential data (altitude, speed)
- **Expanded Mode**: Full instrument panel with all flight data
- **One-Tap Toggle**: Quick expand/collapse with smooth animation
- **Smart Positioning**: Top-left corner, out of the way

### Flight Data Display

#### Primary Instruments
- **Altitude (ALT)**:
  - Current altitude in feet or meters
  - Color-coded for quick reference
  - Real-time updates from GPS/barometer

- **Airspeed (SPD)**:
  - Ground speed in knots, mph, or km/h
  - Accurate GPS-based calculation
  - Unit conversion based on settings

#### Extended Information (Expanded Mode)

- **Heading (HDG)**:
  - Current magnetic heading in degrees
  - Compass rose visualization
  - True/magnetic heading toggle

- **Vertical Speed (V/S)**:
  - Climb/descent rate in feet per minute
  - Positive (+) for climb, negative (-) for descent
  - Color-coded: green (climb), red (descent)

- **GPS Status**:
  - Satellite count and signal strength
  - Position accuracy indicator
  - GPS health monitoring

- **Battery Status (BAT)**:
  - Device battery level
  - Charging status indicator
  - Low battery warnings

- **Time Display**:
  - **UTC Time**: Universal Coordinated Time for aviation
  - **Local Time**: Your current timezone
  - Dual time display for flight planning

## Usage

### Accessing the HUD
1. The HUD appears automatically on the map screen
2. Starts in collapsed mode to minimize screen space
3. Tap to expand for full information

### Customization
- Position adjustable via settings
- Choose which data to display
- Configure units (feet/meters, knots/mph/km/h)
- Set color themes for day/night

## Technical Details

### Data Sources
- **GPS**: Position, speed, heading, altitude
- **Barometer**: Pressure altitude (when available)
- **Device Sensors**: Battery, system time
- **Flight Service**: Calculated vertical speed

### Update Rate
- Real-time updates (1-5 Hz depending on GPS)
- Smooth animations for value changes
- Low battery impact
- Optimized performance

### Display Modes
- **Collapsed**: 80x40 pixels
- **Expanded**: 200x150 pixels
- **Transparent Background**: See-through design
- **High Contrast**: Readable in all conditions

## Best Practices

### VFR Flight
- Keep HUD expanded during critical phases
- Monitor altitude in controlled airspace
- Check speed for airspace restrictions
- Use heading for navigation cross-checks

### IFR Flight
- Use as backup to primary instruments
- Monitor GPS status continuously
- Cross-check with panel instruments
- Verify altitude and heading

### Flight Planning
- Check time displays for ETA calculations
- Monitor ground speed for fuel planning
- Use vertical speed for climb/descent planning
- Track GPS accuracy for route reliability
